Le contexte

Lors de ma scolarité j'ai pu faire du python sur Blender et nous avons été amenés à devoir réaliser un projet sur Blender 2.77.
Dans mon cas j'ai combiner Blockly de google qui permet de programmer comme un puzzle que j'ai intégrée dans ma page web.
Du côté python j'ai dû faire une connexion en socket pour communiquer avec la page web, mais durant l'écoute du port le thread de Blender ce bloque.
Pour résoudre ce problème j'ai tenté de faire du multithreading mais impossible de retourner dans le bon contexte de Blender.
J'ai donc utilisé un timer qui va écouter le port un certain temps puis le couper.

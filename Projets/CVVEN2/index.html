Le contexte

Le conseil d’administration du CVVEN souhaitait un programme de gestion des colloques.
En dehors des périodes de vacances scolaires, le site du Jura peut accueillir des colloques, congrès, séminaires, ou des groupes. Les salles de réunions sont équipées de matériels informatiques, et de vidéoprojecteurs. L’hébergement et la restauration peuvent se faire sur place.

Nous devions concevoir une application en Java liée à une base de données relationnelles.
Voici sont diagramme UML.

Pour la persistance, nous avons décidé d’utiliser le design pattern DAO (Data Access Object).
L’idée du DAO est de lier les données de la base de données avec les objets.
D’abord, il faut créer une classe par entité (table, sans les jointures).
Ensuite, on fait hériter les classes dérivées de la classe mère DAO (qui contient les prototypes des méthodes),
puis on utilise les objets de la classe métier pour implémenter les méthodes des classes dérivées.

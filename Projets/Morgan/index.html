L'entreprise

Qui ? Où ?

J'ai effectué mon stage dans le Cabinet MORGAND, une petite entreprise qui gère l'immobilier et la copropriété, situé à Bastille.

L'existant

Le Cabinet a une tour tournant sous Windows Server 2012 avec SQL Pervasiv.
Leurs postes de travail sont sous Windows 10 Pro x64, équipés d'un Intel i5-34705 ainsi que 4Go de RAM. Antivirus: TREND.
Toute la partie informatique est gérée par une entreprise exterieure sous le nom d'Egide (services informatique d'immobilier). Qui leur offre ses services de dépannage, ainsi que le maintient de leur environnement de travail.
Il utilise un programme sous le nom d'EVEN leur permetant de faire de la gérance, copropriété, comptabilité, et tout se qui est lié au domaine immobilier, ce programme a été fait en Visual Basic.

Réalisation des sauvegardes

Des sauvegardes sont réalisées tous les soirs du lundi au vendredi via Cartridge sur le serveur, un compte rendu est alors généré dans un fichier texte qui est alors transmis par email.

Déroulement du stage

1ère semaine conception du programme désiré + réalisation du programme.
2ème semaine test + gestion des erreurs.
3ème semaine réaménagement du programme (instance pour les connexions).
4ème semaine écriture des docs.

Le projet

Qu'est ce que c'est ?

Il s'agit d'un programme réalisé en C# utilisant la bibliothèque MySql.Data.MySqlClient permettant la gestion de copropriété par le biais de tableaux, le traitement des données via des requêtes, ainsi que l'édition de celles-ci, ce projet a été réalisé avec Visual Studio.

Point fort:
Possibilité de copier-coller vers Excel ou traitement de texte.
Suppression de ligne avec demande de certitude.
Insertion via formulaire (Généré procéduralement).
Modifier les valeurs en direct.
Gestion des erreurs.

Impréssion écran

Dans quel but ?

Il s'agit d'un projet projet réalisé dans le cadre de mon stage de BTS SIO 1ère année.

Pouquoi ces choix ?

Les PC sont tous équipés de Windows avec .Net Framework installé dessus pour l’utilisation du programme en VB.Net déjà présent.
Les langages .Net sont facilement réalisables sous Windows avec Visual Studio et la gestion du design et d’événements qui n’encombrent pas les développeurs.
J’ai donc opté pour le C#.
Je n’ai pas pu avoir l'accés à la base de données du fait quelle soit gérée par une entreprise extérieure.
Donc, j’ai utilisé un SGBD MySQL qui tourne sur une machine virtuelle Ubuntu (utilisé tous deux couramment en cours).

Prérequis

Une machine sous Windows.
.NET Framework 4.5.2 installé.
Une base de données MySQL

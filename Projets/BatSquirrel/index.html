Le contexte

BatSquirrel est un plugin pour Unreal Engine 4.25 actuellement disponible sur le marketplace.
Ce plugin est fait pour pouvoir scripter en Squirrel dans des projets réalisés avec Unreal Engine 4.
Vous devez exposer les éléments qui seront disponibles par le biais du C++ ou des Blueprints.
Pour réaliser ce plugin je me suis inspiré d'un plugin existant s'intitulant LuaMachine.
Il fonctionne actuellement uniquement sous Windows 64bit. Pour en savoir plus vous pouvez jeter un oeil à la documentation.

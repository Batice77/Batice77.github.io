Le contexte

Je me suis dit que j'aimerais faire un projet rapide afin de voir à quelle vitesse je peux réaliser quelque chose et utile.
J'ai donc pensé qu'il serait intéressant de pouvoir faire travailler sa mémoire n'importe où
c'est pour cela que j'ai choisi comme plateforme Android.
Le jeu va donc afficher un nombre composé de quatre chiffres (par défaut) pendant une courte durée
Le joueur se retrouve ensuite avec un pavé numérique afficher sur son écran ainsi qu'une touche verify pour vérifier le nombre entrer les chiffres sont vérifiés un par un si le chiffre est bon il devient vert, mauvais rouge et blanc si le chiffre était manquant.
Il y a un bouton skip pour passer le nombre. Il y a un bouton clear pour effacer toute notre saisi ainsi qu'un slider permettant de régler le nombre de chiffre qui compose le nombre à retenir.
Le projet a été réalisé en une après-midi en comptant toutes les installations nécessaires pour faire un build Android.
